# 🛒 বাজার দর (BazarDor)

A modern web application designed to track, monitor, and compare daily essential market prices across various categories in Bangladesh with accuracy and clarity.

---

## 🚀 About the Project

**বাজার দর (BazarDor)** provides localized, up-to-date market prices for daily necessities such as rice, lentils, vegetables, meat, and fish. Built with modern web technologies, the platform delivers a fast, responsive, and light-themed user experience for checking price fluctuations and daily changes.

---

## 🛠️ Technologies Used

* **Framework:** Next.js (App Router)
* **Library:** React
* **Styling:** Tailwind CSS, HeroUI
* **Authentication:** Better Auth
* **Database:** MongoDB
* **API Integration:** Programming Hero Open API (`/bazardor/products`)
* **Deployment Platform:** Vercel / Netlify

---

## ✨ Key Features

1. **Live Market Price Tracking:** Displays daily updated prices and real-time percentage changes (up, down, or stable) for essential household commodities.
2. **Dynamic Category Filtering:** Allows seamless browsing through structured categories (চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ, মসলা) using dynamic routing (`/categories/[slug]`).
3. **Price Sorting & Search:** Enables users to organize market products by price (low-to-high, high-to-low) for efficient price comparison.
4. **Bangla Localized UI:** Features complete Bengali typography, custom digit conversion, and localized unit measurements (কেজি, লিটার, ডজন, টি).
5. **Secure Authentication & Light Theme UI:** Offers seamless user authentication via Better Auth alongside a clean, modern emerald light-mode layout.
